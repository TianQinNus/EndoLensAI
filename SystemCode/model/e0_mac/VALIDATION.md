# E0 validation scope

Historical preparation verified synthetic image/mask pairing, merged-source mapping, native-resolution probability/mask consistency, binary metrics, duplicate handling and safe output behavior. A real CPU smoke exercised the original model; full completed798-entry results were subsequently replay-checked.

These checks do not prove patient independence, negative-frame specificity, MPS support or clinical/video performance. See [completed results](../../../ProjectReport/E0_E4_BASELINES.md). This documentation migration does not rerun the historical experiment.
